见行修学 · 运营使用说明（简明版）

网站：https://jianxing.win
后台：https://jianxing.win/ops/

后台链接只发给负责维护内容的师兄，请勿发到公开群。

1. 登录

  1. 打开后台地址
  2. 输入运营密码（向管理员索取）
  3. 登录成功即可使用

密码错误或登录过期时，重新登录即可。

2. 后台有三个区

顶部三个标签，各管一类内容：

标签管什么前台在哪看
学修模块、章节、课文、音视频首页 / 学修页
参考书籍PDF 等书籍材料参考资料 → 参考书籍
公众号好文好文集合与文章参考资料 → 公众号好文

切换标签前，若有未保存修改，系统会提示。请先点保存。

3. 学修：怎么改课

内容层级：

模块（如：大圆满前行-讲解）
  └── 章节
        └── 课
              ├── 文字
              ├── 音频
              └── 视频

3.1 选模块 / 新建模块

  • 左侧点模块名称进入
  • 可用搜索、状态筛选快速找模块
  • 点「+ 添加」新建模块（默认「即将开放」）

3.2 设置模块（很重要）

进入模块后可改：

项目说明
标题 / 摘要前台显示的名称与简介
状态开放中＝学员可学；即将开放＝占位待开
学修分区决定出现在学修页哪一块
专业课子组仅当分区选「专业课」时出现

学修分区可选：
基础课 / 公共学修 / 专业课 / 实修篇 / 见行选修 / 未归类

选「专业课」时，再选子组：大圆满前行 / 菩提道次第广论。
选「未归类」或未设置，会出现在前台「未归类」。

改完后点顶部 「保存到服务器」。

3.3 搭章节和课

  1. 「+ 添加章节」
  2. 在章节下「+ 添加课」
  3. 按住左侧 ⋮⋮ 可拖拽排序
  4. 点 「保存到服务器」

3.4 编辑一课内容

点课上的 「编辑内容」：

  • 文字：写本课讲记
  • 音频 / 视频：选文件上传（大视频会自动分片）

说明：

  • 上传成功会自动保存
  • 只改文字或结构调整时，需手动点 「保存到服务器」
  • 可以先只上文字，音视频以后再补

3.5 建议顺序

  1. 先搭模块 → 分区 → 章节 → 课，保存
  2. 再逐课写文字、上传音视频
  3. 打开前台学修页核对位置和内容

4. 参考书籍

  1. 顶部点 「参考书籍」
  2. 先从列表进入某一本，再改标题、说明、上传文件
  3. 上传成功一般会自动保存；改文字后请点 「保存到服务器」

前台路径：参考资料 → 参考书籍。

5. 公众号好文

  1. 顶部点 「公众号好文」
  2. 先从列表进入某一集合，再编辑
  3. 保存时点 「保存好文」（与学修课表分开保存）

集合有两种：

类型用法
链接型集合本身就是一个外链，学员点集合即打开链接
文字型在集合内再添加多篇文章

前台路径：参考资料 → 公众号好文。

6. 务必记住

  1. 改了记得保存（顶部黄条提示时务必点保存）
  2. 学修 与 公众号好文 是两套保存，按钮文案不同
  3. 删除模块 / 章节 / 课，保存后才会真正生效，请谨慎
  4. 上传大视频时保持页面打开，直到提示成功
  5. 多人同时改同一内容可能冲突，按提示重新加载后再改
  6. 密码勿外传

7. 常见问题

改了课标题，以前的链接会坏吗？
一般不会。系统用内部标识认课，标题可以改。

能不能先只上文字？
可以。音频、视频留空即可。

新模块前台找不到？
检查三点：是否已保存、状态是否「开放中」、学修分区是否选对。

模块出现在「未归类」？
进入该模块，把「学修分区」改成正确分区，再保存。

改完前台没变化？
先确认已保存成功，再刷新前台页面（可强制刷新）。

8. 需要帮助时

联系站点管理员，说明：你在改哪一块（学修 / 书籍 / 好文）、哪一个模块或集合、大约什么时间操作、页面提示了什么。
